# CleanShot X local parity ledger

Baseline: official public feature inventory and release notes inspected 2026-09-05.
This is a replacement implementation, not the macOS binary, and does not use its
branding, proprietary source, image assets, or proprietary project format.
Cloud hosting, syncing, collaboration, transcription, teams, and account management
are excluded by request. Nothing uploads captures.

## Acceptance rule

A feature is complete only when its user workflow is implemented and verified.
An available command, a button, or a unit test alone does not establish UI parity.
Exact behavior on macOS cannot be certified without a running reference copy;
public documentation and visual references are the initial interaction specification.
